## 三阶段推荐架构

1. **离线索引**: 文件 → VLM/ASR/CLAP → Embedding → Qdrant
2. **在线检索**: 查询 → 向量化 → Qdrant Top-K=100 → RRF融合
3. **精排解释**: Reranker Top-100→Top-20 → MMR Top-20→Top-10 → LLM推荐理由

---

## 两种推荐模式

| 维度 | 查询驱动搜索 | Item-to-Item 推荐 |
|------|------------|------------------|
| 触发 | 用户输入文字/图片/音频 | 客户端传已索引的 item_id |
| 向量来源 | 实时计算 | 从 Qdrant 取回已存储向量 |
| 计算开销 | 需要跑模型 | 零重复计算 |
| 延时 | 3-8s | 2-5s |
| API | `POST /api/v1/search` | `POST /api/v1/recommend` |
