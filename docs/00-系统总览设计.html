01系统概览

目标

在单台 24GB MacBook Pro (M5) 上构建全模态内容推荐系统，支持对图片、视频、音频三种媒体类型进行自动理解、标签生成、向量化索引和相似推荐。

核心能力

图片
VLM 生成描述 + 标签
VL-Embedding 直接向量编码
视频
三模式：仅画面 / 仅声音 / 画面+声音并行
双轨道独立向量化 + 融合检索
音频
语音：ASR 转写 + 文本嵌入
音乐/环境音：CLAP 直接音频嵌入

系统特点

  • 模块化设计：画面、声音、图片、文本各自独立模块，统一接口输出 {vector, description, tags}，业务层自由组合
  • 视频双方案：直接传送（短视频/快速原型）与 ffmpeg 抽帧（长视频/生产环境）自动选择或手动指定
  • 双路向量化：VLM 理解路（生成富文本描述）+ VL-Embedding 快速路（直接图像向量），兼顾精度和速度
  • 视频双轨道分析：支持仅画面、仅声音、画面+声音并行三种模式，自动判断或用户指定，双轨道独立向量化后融合检索
  • 全音频覆盖：语音走 ASR 转写 + 文本嵌入；音乐/环境音走 CLAP 直接音频嵌入，两种路径统一到同一向量空间
  • 三阶段推荐：向量检索 Top-K → Reranker 精排 → LLM 生成推荐理由
  • 自动标签体系：VLM + LLM 协同生成多级标签（类别、风格、情绪、场景）；音频标签由 CLAP 分类 + ASR 内容提取
  • 全本地运行：无需云服务，数据隐私 100% 保障
  • 统一内存管理：三级加载策略（常驻/热缓存/冷加载），24GB 内存精细分配

03系统架构设计

三阶段推荐架构

系统采用业界最佳实践的 Retrieval-then-Rank 三阶段架构：

双路向量化设计

理解路 (VLM Path)

流程：媒体 → VLM → 富文本描述 → 文本 Embedding

优势：深度理解，可生成标签和解释

用途：入库时生成完整索引 + 查询时生成描述

延时：~3-5s/图片，~10-30s/视频

快速路 (VL-Embedding Path)

流程：图片 → VL-Embedding → 直接向量

优势：快速，无需文本中间步骤

用途：查询时快速图片检索 + 辅助索引

延时：~0.3s/图片
